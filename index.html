/* ======================================== Google Sheets 연동 API 설정 정석비행훈련원 입과자 통합관리 플랫폼 ======================================== */ const API_BASE = 'https://script.google.com/macros/s/AKfycbzumoikKGJePSgX7t2Ov8y4zrwuUw3vxkU5mxWn_MgUBqsCw-E-HE0ZPN5_Rehyd3Bb/exec'; // API 공통 호출 함수 (조회) async function apiGet(action, params={}) { try { const qs = new URLSearchParams({action, ...params}); const res = await fetch(API_BASE + '?' + qs.toString()); const data = await res.json(); return data; } catch(e) { console.error('API GET 오류:', e); return {success:false, message:e.message}; } } // API 공통 호출 함수 (저장) async function apiPost(action, payload={}) { try { const res = await fetch(API_BASE, { method: 'POST', headers: {'Content-Type': 'text/plain;charset=utf-8'}, body: JSON.stringify({action, payload}) }); const data = await res.json(); return data; } catch(e) { console.error('API POST 오류:', e); return {success:false, message:e.message}; } } // 입과자 목록 서버에서 불러오기 async function reloadTrainees() { try { document.getElementById('tr-stat-bar').textContent = '⏳ 데이터 불러오는 중...'; const result = await apiGet('trainee.list', {pageSize:500}); if(result.success && result.data) { trData = result.data; } populateTrFilters(); renderTrainees(); } catch(e) { document.getElementById('tr-stat-bar').textContent = '⚠ 데이터 로딩 실패: ' + e.message; } } // 입과자 저장 (서버) async function saveTrItemToServer(item) { const result = await apiPost('trainee.save', item); if(!result.success) throw new Error(result.message || '저장 실패'); return result; } // 입과자 삭제 (서버) async function deleteTrItemFromServer(id) { const result = await apiPost('trainee.delete', {id}); if(!result.success) throw new Error(result.message || '삭제 실패'); return result; } // 입과자 업로드 (서버) async function uploadTraineesToServer(rows) { const result = await apiPost('trainee.upload', {rows}); return result; }
